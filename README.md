- 🟡 **앤트로픽 상장에도 지속되는 '유동성 한파'** — 앤트로픽 주가 급등 등 일부 개별 이벤트에도 불구하고 시장 전반의 투매와 유동성 부족을 되돌리지 못하고 있습니다.
