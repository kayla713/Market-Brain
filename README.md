AI 관련주 고평가 논란과 글로벌 유동성 축소 압력 속에서 기술주 중심의 추세적 하락세가 여전히 유효합니다. 따라서 주식 비중을 보수적으로 유지하고 채권, 금, 현금 등 안전자산 중심의 방어 포트폴리오를 유지하는 것이 적절합니다.
